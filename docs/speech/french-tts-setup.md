# French speech synthesis

The selected engine is **Piper 1.8.0**, using **fr_FR-siwis-medium**. The voice's own [model card](https://huggingface.co/rhasspy/piper-voices/blob/main/fr/fr_FR/siwis/medium/MODEL_CARD) specifies French (France), one speaker, 22,050-Hz output and the [SIWIS dataset](https://datashare.is.ed.ac.uk/handle/10283/2353) under CC-BY 4.0. Attribute the SIWIS French Speech Synthesis Database and the published Piper voice when distributing the model and related documentation. The card notes fine-tuning from a Lessac voice; it does not establish “native accent” certification. Keep the original model card with the weights.

The current [Piper engine](https://github.com/OHF-Voice/piper1-gpl) is GPL-3.0-or-later, separately from voice/dataset licensing. The optional worker packages the engine as its own service; preserve its notices/source obligations when distributing that worker. The application's UI includes voice/dataset attribution. No voice cloning, reference-speaker upload or paid API is introduced.

Provisioning and Docker commands are in [ASR setup](faster-whisper-setup.md). The voice is local ONNX plus JSON configuration, not an OS/browser English voice. At load time the worker checks that the configured voice language begins with `fr`. Missing voice/configuration or synthesis errors return unavailable; it never substitutes English speech. The Piper API writes mono 16-bit PCM WAV at the configured voice's rate. The backend validates that output, records the actual waveform duration/checksum and returns an owned asset only after synthesis succeeds.

Voice conversation responses use the existing tutor, with a French speaking instruction. A conservative language check selects at most three sentence chunks and 600 characters before any explicit English explanation section. If French selection is uncertain, text remains available and audio is unavailable. Language classification is a heuristic, not linguistic certification. The selected spoken text is returned and displayed alongside the audio; TTS retry regenerates that saved text rather than asking the tutor again.

Use Play/Replay in Voice Practice. There is no autoplay. Playback-speed controls change HTMLAudioElement playback speed, initialized from the existing user preference; they do not claim model-level CEFR voice-speed control. Headphones help avoid recording the reference audio as microphone input.

Live verification generated and decoded real WAV output, transcribed a synthesized French boulangerie phrase and exercised the complete ASR → Ollama → TTS flow. That checks synthesis/transcription correspondence for a sample, not an independent human evaluation of accent, naturalness or arbitrary pronunciation. Actual observed byte sizes and timings are recorded in the verification report.
