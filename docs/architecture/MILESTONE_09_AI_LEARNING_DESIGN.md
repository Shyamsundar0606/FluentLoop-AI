# Milestone 09 design

M05 already owns tutor sessions, message history, an inference lease, retry
IDs, lesson citations and structured sentence corrections. M06 sends confirmed
text through that same tutor service and keeps audio assets under its existing
retention rules. M07 owns vocabulary schedules and daily plans. M08 owns
lesson progress, saved attempts and draft permissions.

The coach extends the existing conversation and preferences records. It uses
bounded evidence from published activity and the selected CEFR level.
Scenario goals and examples are original practice prompts. Completion is a
learner action, and summaries distinguish observed activity from scenario
goals. No model output advances CEFR or updates vocabulary schedules.

The previous scenario catalogue already covers seven requested situations.
Transport, pharmacy and doctor practice need original prompts. The coach
also needs difficulty, correction timing, completion and a shared summary
for text and speech. Vocabulary examples drawn from globally linked lexemes
need additional caution because those links can span draft lessons.
