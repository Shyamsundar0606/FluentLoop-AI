# Milestone 08 release readiness

**Public publication is blocked.** The actual A1 courses have zero published
lessons and all five independent review categories are pending. Technical
validation is evidence for reviewers. Release authorization requires genuine
review evidence and a verified administrator decision.

The canonical starter publication command checks the exact source version,
importer and source digests, database-to-source integrity, lesson sequence,
exercise keys and the legacy human review record. It also checks that all five
independent categories have current approvals for the packet digest, that
blocking corrections are resolved, and that licensing evidence comes from an
independent reviewer. The administrator decision must follow the recorded
reviews. Synthetic approvals and publication simulation are test-only.

The release command is scoped to the canonical ten-lesson starter. The
interactive fixture and grammar supplement are preview releases. The
canonical command blocks while any linked grammar dependency is still
marked draft or under review. The existing demo has shared draft grammar
dependencies that need a scoped publication decision before release.

Existing learner history and the production configuration were outside the
write scope. The earlier M08.3 backup restoration remains documented in
[the M08.3 verification report](MILESTONE_08_3_VERIFICATION.md). A fresh
proven backup and explicit approval are required before a persistent data
change.

The next recommended milestone is independent curriculum review and a
publication decision once the review and scope blockers are cleared.
