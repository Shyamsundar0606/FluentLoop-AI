# Depth dossiers: staged only

Five cohesive modules contain 15 lessons and 20 scored exercises plus five open
writing/speaking transfer tasks. A0/A1 provide supported classroom repair and
appointment sequences. B2/C1/C2 pair two substantial original inputs before an
extended productive task; combined French input exceeds 300 words per advanced
dossier. The input lessons test different argumentative targets, not duplicated
sentences added to inflate counts.

Every module links Input 2 to Input 1 and the transfer task to both inputs.
Notes teach contextual grammar and expression, followed by task-specific review
criteria and delayed retrieval. No new SRS glossary entries are inserted by these
packs; additional structured vocabulary/grammar records remain a coverage gap.
The vocabulary is practised in context, not represented as complete lexical coverage.

Listening uses original scripted excerpts with existing local speech synthesis.
It does not supply authentic multi-speaker, varied-accent or spontaneous listening;
those remain gaps. Open tasks are reviewed qualitatively; word ranges and quiz
scores do not certify a CEFR level. French, answer-key scope and pedagogy have
AI-assisted review and automated validation, not independent human approval.
