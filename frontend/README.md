# Frontend

Next.js App Router interface for FluentLoop AI. See the [project README](../README.md) for secure setup, architecture, optional local models and testing.

Run `npm ci`, then `npm run dev` for native development. Configure `NEXT_PUBLIC_API_BASE_URL` for your isolated API. Public browser variables must never contain credentials. Lint, typecheck, build and Playwright scripts are defined in `package.json`.
